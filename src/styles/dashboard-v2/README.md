# نظام لوحة مَلِكات V2

هذا المجلد نظام مستقل تمامًا عن CSS القديم. الغرض منه نقل صفحات لوحة الإدارة تدريجيًا بدون كسر الصفحات الحالية.

## قواعد إلزامية

1. الاستيراد يتم من `dashboard-v2.css` فقط.
2. جميع القواعد محصورة تحت `.dashboard-v2`.
3. جميع المكونات الجديدة تبدأ بالبادئة `dsv2-`.
4. يمنع وضع ألوان Hex داخل ملفات الصفحات؛ تستخدم المتغيرات من `tokens.css`.
5. يمنع استخدام `!important` داخل النظام الجديد إلا عند التعامل مع مكتبة خارجية موثقة.
6. ملف الصفحة يحتوي اختلافات الصفحة فقط، وليس نسخًا جديدة من الأزرار والكروت والجداول.
7. لا يحذف أي CSS قديم قبل اكتمال نقل الصفحة واختبار البناء والجوال.

## لوحة الألوان المعتمدة

- ذهبي: `#D9A50B`
- أسود: `#05080D`
- عنابي: `#59041B`
- أخضر: `#177348`
- رمادي الصفحة: `#F2F2F2`

## ترتيب النقل

1. اعتماد صفحة المعاينة `/dashboard/design-system-v2`.
2. الصفحة الرئيسية `/dashboard/overview`.
3. الإيرادات والمصروفات والتقارير.
4. العملاء والموظفات والرواتب والتارقت.
5. العمليات والعروض والسجلات والإعدادات.
6. حذف ملفات CSS القديمة غير المستخدمة بعد التحقق من كل صفحة.
