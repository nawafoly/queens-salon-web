# تنظيف جميع سجلات العملاء القديمة دفعة واحدة

هذا التصحيح يوقف معالجة التعارضات رقمًا رقمًا.

## السلوك

- يفحص جميع أرقام الجوال المكررة في Core D1 دفعة واحدة.
- يدمج تلقائيًا فقط النمط الآمن: سجل قديم معرفه رقم جوال + سجل واحد مرتبط بـFirebase UID.
- ينقل الحجوزات والفواتير والدفعات والاسترجاعات والنقاط والباقات والجلسات والاستهداف والـaliases.
- يجمع جميع الحالات غير الآمنة في تقرير واحد بدل التوقف عند أول حالة.
- لا يدمج رقمًا مشتركًا بين عميلتين إذا لم يكن هناك سجل قديم معرفه رقم الجوال.
- ينشئ نسخة احتياطية قبل التطبيق.
- يجعل ترحيل Packages يثق بتطابق Firebase UID الأقوى حتى لو بقي سجل جوال قديم مؤقتًا.

- `core-client-dedup-main.sql.report.json`
