إصلاح الباقات والجلسات — الحذف والواجهة

الإصلاحات:
1) إصلاح نافذة تأكيد الحذف وإظهارها في منتصف الشاشة بدل التعتيم بدون نافذة واضحة.
2) إزالة الارتفاع الإجباري الذي كان يسبب فراغًا أبيض كبيرًا أسفل الجدول.
3) ضبط أزرار تعديل/حذف وتخطيط الجدول على الكمبيوتر والجوال.
4) تنفيذ الحذف عبر DELETE أولًا مع fallback تلقائي إلى POST للتوافق مع نسخ Packages Worker القديمة والجديدة.
5) حذف سجل حركات الباقة ثم الباقة من D1 والتحقق فعليًا من اختفاء السجل.
6) منع حذف الباقة إذا كان عليها جلسات محجوزة وإظهار سبب واضح.

نتائج التحقق:
- Packages Worker: 32/32 ناجحة.
- Frontend Core: 27/27 ناجحة.
- npm run build: ناجح.

مهم:
يجب نشر Packages Worker لأن الإصلاح يشمل workers/packages/routes.js.
